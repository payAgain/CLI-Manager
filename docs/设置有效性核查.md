# 设置有效性核查

版本：0.1.0（开发中，未发布）。核查日期：2026-10-22。

核查当前 11 个设置页、Settings 字段及模板、SSH、历史来源等独立存储，逐项追踪界面操作、持久化、运行消费方和平台条件。这里只记录当前精简版本的行为，不重新启用已移除的功能。

## 发现并处理的问题

| 问题 | 处理结果 |
| --- | --- |
| 历史来源使用供应商图标推断，Copilot、Antigravity、Pi 等回退为文件夹 | 统一复用完整的 Agent 图标映射，恢复项目选择也采用同一映射 |
| Codex 子代理的可读思考摘要未解析 | 补齐 `reasoning.summary` 和旧版思考事件，兼容 Claude thinking，过滤父记录及重复表示；加密内容保持不可读 |
| 所有子代理命令逐行铺开 | 新增可保存的摘要／完整模式，摘要合并连续操作，完整逐项展示，均保留原始详情 |
| 子代理完成后自动关闭，结果无法继续查看 | 自动收起改为将结果标签移回主会话窗格，保留输出；正在阅读时不收起，隐藏 Workspan 不抢焦点，手动关闭才移除 |
| TUI 每次滚轮只得到一次操作 | 新增 1–10× 倍率，默认 3×；由 xterm 继续处理编码、方向、坐标与触控板增量 |
| 应用深浅切换时，独立终端主题仍保持原色，界面没有明确区分 | 顶部增加明确的配色模式及当前主题；分类筛选不再隐式切换模式，选择具体主题才启用独立配色 |
| 仅主题改变、网格和渲染器不变时缺少显式全量刷新 | 统一清理可见 WebGL 字形缓存并请求全量重绘；隐藏期间记录刷新需求，显示后补绘 |
| 关闭项目 Worktree 配置只隐藏表单，旧项目仍可能自动隔离 | 在共用启动决策中检查开关，关闭后普通启动；已有项目策略保留，重新开启后恢复使用 |
| WSL 软连接开关及目录入口出现在非 Windows 平台 | 开关和入口均按 Windows 条件展示 |
| 旧侧栏工具栏、常驻资源监控和弹窗开关已无消费方 | 移除有效字段、默认值与旧迁移读取，加载时忽略旧键；不删除磁盘上的旧配置和历史 |

## 当前设置的消费方与生效范围

| 设置页 | 核查的选项 | 消费方与生效条件 |
| --- | --- | --- |
| 通用 | 语言、应用深浅主题、浅／暗配色、界面字体、字号、文字颜色 | `App.tsx`、i18n、主题和字体应用链；即时更新。独立终端配色由终端页单独控制 |
| 通用／数据目录 | 当前目录、切换／恢复默认目录、已有数据检查 | `DataStorageSection` → `app_paths.rs`；受发行形式、活动终端、后台操作和 SSH 安装状态限制，切换按界面提示重启 |
| 智能体 | 启动权限、已安装工具与命令预览 | `agentLaunchPermissions`、CLI 检测与终端启动链；影响后续启动，保留项目显式参数及环境边界 |
| 终端 | 跟随／独立主题、主题卡片、字体／字号、文字和 TUI 颜色、背景 | `XTermTerminal`、`useTerminalDisplay`、TUI 颜色同步和背景组件；即时更新，隐藏窗格在显示后补绘 |
| 终端 | TUI 滚轮倍率、自定义回滚行数 | 浏览器鼠标策略、xterm 参数；倍率即时生效，普通历史和 Shift 回滚不加速；回滚行数影响本地保留范围，不能恢复 CLI 已主动清除的内容 |
| 终端 | 默认 Shell、Shell 扫描／启用／自定义 | Shell profiles、项目表单及终端启动；主要影响新项目或新终端，不重启已有 Shell |
| 终端 | 关闭按钮、退出任务策略、已完成任务检测、标签关闭确认、恢复方式 | `App.tsx`、关闭／退出／恢复流程；分别在对应操作或下次启动时生效 |
| 终端 | Unsplit、标签悬浮信息、外部终端、分组启动方向、项目筛选、Workspan、状态标记 | 终端 store、侧栏和标签／分屏渲染链；外部启动与分组策略在相应启动操作中生效 |
| 终端 | 通用 Shell 运行监控 | 终端启动包装及 daemon 状态；当前用于新建 PowerShell／pwsh，会话 Hook 与此分开处理 |
| 快捷键 | 换行组合键、标签切换组合、动作录制／清除／恢复、冲突提示 | `useKeyboardShortcuts` 和终端输入处理；即时应用 |
| 命令模板 | 列表／搜索、新建／编辑／删除、全局／项目范围、最近命令转存 | 模板 store、SQLite、终端模板入口；实际保存和删除路径仍有效 |
| SSH 主机 | 主机／分组、导入、认证／跳板、测试、远端 Agent 安装 | SSH store、Rust SSH 命令和安装队列；按主机连接或安装时生效，远端工具能力仍遵守现有只读边界 |
| 历史会话 | 来源开关、路径、自动检测、保存／清除、备份／恢复 | 历史来源 store、索引、目录校验和备份命令；本地／WSL／SSH 来源按现有范围隔离，恢复继续进行冲突检查 |
| Hook | 自动子代理分屏、完成后收起及延迟、摘要／完整模式 | `terminalStore` 与子代理面板；显示模式即时更新，关闭自动分屏只影响后续创建；完成结果保留为标签，关闭自动收起则保留分屏 |
| Hook | CLI 桥接、模块安装／卸载、路径、系统通知、事件筛选、前台抑制、任务栏提醒 | Hook 管理命令、daemon 归属校验和通知 dispatcher；区分焦点、隐藏／托盘、CLI 类型与平台能力；桥接安装状态独立检查 |
| Hook | 第三方通知匹配与目标 | Rust `third_party_notification/dispatcher.rs` 读取设置；只有相应桥接和匹配规则满足时才投递 |
| 侧边栏 | 紧凑模式、列表密度、项目过滤按钮、面板合并／互斥、皮肤、工具栏入口、统计／资源卡片显示及顺序 | `App.tsx`、侧栏、`TerminalTabs`、资源弹层与统计组件；即时应用。资源按弹层可见状态采样，不使用已删除的旧常驻采样开关 |
| 开发者 | 恢复终端、项目 Worktree 配置、低内存、硬件加速、调试日志 | 启动／恢复、Worktree 决策、渲染器生命周期和日志命令；低内存／WebGL 按会话更新，恢复策略在下次启动时使用 |
| 开发者 | WSL 软连接、ConPTY 兼容修复、Codex 光标隐藏、Linux 图形模式／诊断 | 界面按平台展示；ConPTY 和 Linux 启动环境调整按提示重启，WSL 目录入口仅 Windows 使用 |
| 关于 | 当前版本、仓库链接与精简版发布说明 | `get_app_version` 与系统 URL 打开接口；没有遗留供应商管理、桌宠或旧更新器设置 |

分区折叠、卡片排序、面板宽度、上次设置页等字段用于界面状态记忆，属于有效设置；不能因为没有终端执行消费方就判定为失效。

## 验证边界

使用现有 Node 回归测试、TypeScript 检查、Rust 检查及本机浏览器中的真实 xterm 验证。浏览器预览只使用合成记录与内存设置，不修改用户的 Hook、会话或配置。

Windows／WSL／SSH 的条件及调用方已核对；本轮未连接远端机器或执行真实 Hook 重装，也没有重启当前运行的应用和 daemon。跨平台行为仍需对应环境的实机验证。
