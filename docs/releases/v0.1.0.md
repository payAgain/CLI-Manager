# CLI-Manager v0.1.0

发布日期：2026-10-25

这是 CLI-Manager 精简版的首个正式发布，围绕项目、AI 终端、历史对话和代码变更组织日常开发工作。

## 下载与安装

| 文件 | 用途 |
| --- | --- |
| [CLI-Manager-0.1.0-macos-arm64.zip](https://github.com/payAgain/CLI-Manager/releases/download/v0.1.0/CLI-Manager-0.1.0-macos-arm64.zip) | macOS Apple Silicon 应用，解压得到 `CLI-Manager.app`。 |
| [SHA256SUMS.txt](https://github.com/payAgain/CLI-Manager/releases/download/v0.1.0/SHA256SUMS.txt) | 校验下载的 ZIP。 |

将两个文件放在同一目录，执行：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

ZIP 同时附有许可证、第三方归属声明和 `SOURCE.txt` 对应源码链接。解压后将 `CLI-Manager.app` 移至“应用程序”；替换已有版本前先退出旧版。CLI 工具需自行安装并登录，应用沿用各工具自己的认证与配置。

应用使用 ad-hoc 签名，未经过 Apple 公证。若 macOS 拦截首次启动，确认来源及校验值后，先尝试打开一次，再在**系统设置 → 隐私与安全性 → 仍要打开**中确认。参见 [Apple 官方说明](https://support.apple.com/en-us/102445)。

本次发布为 `.app` ZIP，不提供 DMG。Intel Mac、Windows 和 Linux 暂无本版预编译安装包，可使用 [v0.1.0 源码](https://github.com/payAgain/CLI-Manager/tree/v0.1.0)构建。

## 主要功能

- **项目与 Worktree 工作区。** 项目分组、文件夹导入和快速跳转；分支、所属终端和状态点在同一卡片展示。自动发现外部创建的 Worktree，移除前检查未提交改动、运行会话和目录占用，默认保留分支。
- **持久终端与并行布局。** 原生 PTY、分屏和 Workspan，独立 daemon 保留后台终端；重开应用可附着原进程并回放输出。Unicode、输入法、隐藏后重绘与终端资源回收经过专项修复。
- **准确恢复与快速继续。** 支持的 Agent 按准确会话 ID 恢复，历史列表可直接继续对话；已运行且身份匹配的终端直接定位。保留项目／Worktree 目录及来源配置，隔离本地、WSL 发行版和 SSH 主机。
- **历史与代码检查。** 浏览、搜索多种 CLI 历史，查看消息、子代理和 Diff；本地文件编辑、Git 变更、代码快照、审核与恢复集中在工作台中。操作随来源和环境能力开放。
- **Hook 通知与未读收件箱。** 跟踪当前会话的工作、审批、完成及失败状态；系统通知和持久收件箱可跳回准确终端，保留前台、后台和不同工作区的归属边界。
- **任务与资源视图。** 会话任务清单、计划、后台命令和子代理分组展示；保留终端与应用操作单列。资源管理器按工作区、终端、Agent／进程展示实际内存采样与归属。
- **紧凑桌面交互。** 中英文、繁体转换、24 小时制、主题与命令模板；右侧栏可整体收起，展开后恢复选中的面板。空任务分组不再显示说明小字。

## 本版修复

- 合法大消息、图片和长工具参数不再整条丢弃，也不再导致任务状态永久“待确认”；保留有界读取和准确身份检查。
- 读取失败时保留条目内容并撤销旧确认状态，成功读取后再更新；“读取提示”解释具体原因。
- Worktree 删除统一使用检查与明确确认，覆盖外部工作区、后台会话和检查后状态变化；原始会话历史文件保留。
- 改进后台／隐藏终端恢复、手动启动 Agent 的识别，以及 Hook 和通知的准确会话绑定。

## 支持范围

- 本次预编译包及本机验证覆盖 macOS Apple Silicon；其他平台及 WSL／SSH 的实机组合仍需分别验证。
- SSH 提供远端终端、分屏、模板和只读文件／Git／历史视图；远端 Worktree 管理及面板写操作暂不提供。本包未内置 Linux SSH Agent，首次安装或更新增强功能需联网访问既有可信签名分发源，或使用已安装的兼容 Agent。
- 浏览、恢复和 Hook 能力随 CLI 来源而异；缺少准确会话 ID 时不按同目录的最近记录猜测身份。
- 保留既有数据库迁移和历史文件。已移除桌宠、供应商管理与配置注入、命令建议、Statusline 管理、cc-connect、WebDAV 同步、历史统计、请求记录和 ccusage。

完整记录见 [CHANGELOG](https://github.com/payAgain/CLI-Manager/blob/v0.1.0/CHANGELOG.md) 和[功能清单](https://github.com/payAgain/CLI-Manager/blob/v0.1.0/docs/%E5%8A%9F%E8%83%BD%E6%B8%85%E5%8D%95.md)。

## English summary

CLI-Manager Lean Edition v0.1.0 is the first release of this fork: a project workspace for AI CLI terminals, Worktrees, conversation history, and code review.

- Organize projects, branches, terminals, and status indicators in workspace cards; safely review changes and active sessions before removing a Worktree.
- Use persistent PTY terminals, splits, and Workspans; reconnect to surviving processes or resume supported conversations by exact session ID.
- Continue conversations directly from history, review Git changes and Diff, and follow Hook notifications in a persistent unread inbox.
- Inspect session tasks, plans, background commands, and real workspace/terminal/process memory samples. Large transcript records and long tool arguments are parsed with bounded reads.
- Keep readable task content after a failed read while marking its state unconfirmed; restore confirmed states only after a successful read.

The downloadable build is **macOS Apple Silicon (arm64)**, packaged as a ZIP containing `CLI-Manager.app`, with `SHA256SUMS.txt`. License texts, third-party notices, and a corresponding-source link are included in the ZIP. The app is ad-hoc signed and not Apple-notarized. After verifying the source and checksum, follow [Apple's first-launch instructions](https://support.apple.com/en-us/102445) if macOS blocks opening it. Intel Mac, Windows, and Linux release installers are not included; source builds remain available.
