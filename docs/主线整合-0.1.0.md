## 整合修复

- 工作区归属与终端运行环境分开：本地项目使用 WSL Shell／启动包装时，创建、冷恢复、daemon 附着和旧通知匹配识别实际运行环境，项目与 Worktree 归属不变；SSH 主机与 WSL 发行版继续隔离。
- 外部 Hook 的唯一终端归属恢复与新鲜定向观察结合：不按共享目录猜绑，不恢复逐 Hook 全系统扫描。Windows 共用一次 Job／PID 观察与新鲜采样等待；保留首次 Hook、来源不匹配、独立 Agent 歧义拒绝和远端候选排除。
- 已退出／失败的 Worktree 恢复标签保留迟到 Hook 与 daemon 观察保护；恢复测试同时使用快照缓存和真实 daemon 附着入口。
- 旧源码正则测试改为生产入口的行为验证；测试环境补齐 mutation gate、会话状态与准确身份，继续验证外部客户端隔离、未保存文件和捕获期间设置变更。
