# CLI-Manager 精简版功能清单

> 版本：0.1.0（开发中，未发布）
> 更新：2026-10-23。本文记录当前精简分支的功能边界；历史版本的变更请查看 CHANGELOG.md。

## 项目和终端工作区

- 0.1.0 工作区卡片显示终端总数，选中后逐项列出终端名称和独立的 Agent 标记，终端行不添加编号，高亮当前项并支持点击切换；紧凑模式及未选中卡片仍显示数量。同目录历史终端即使未绑定项目 ID 也参与列表、数量、筛选与定位，主工作区／Worktree、本地／WSL／SSH 归属独立，保留原启动元数据与 Hook、分屏／Workspan 状态。

- 0.1.0 CLI 工具选择仅列出所选 Shell 环境中已安装且可调用的工具，支持本机、WSL 和 SSH 独立检测、手动刷新及空／失败状态；保留自定义输入和已保存值。检测只查询命令，不运行 Agent，限时异步执行，环境切换不显示旧主机结果；智能体设置页复用检测筛选。

- 0.1.0 项目与 Worktree 的启动入口明确区分“启动 Agent／运行启动命令”和“新建空白终端”；未配置启动命令时仅保留一个空白终端入口。空白终端保留项目环境、Shell 和工作目录，明确禁止 SSH 回退执行项目启动命令，不预先绑定 Agent 身份；支持后续手动启动和 Hook 自动绑定。

- 0.1.0“设置 > 智能体”提供手动／YOLO 启动权限与命令预览，展示当前 Shell 中全部已安装工具（含 Pi、Goose）；未保存选择时默认 YOLO，保留显式手动选择。支持为 Claude Code、Codex、Kimi、Grok、Qwen、Gemini、Copilot、Cline、Amp、Aider、Crush 添加各自的权限参数，Pi 沿用原生权限。覆盖本地／WSL／SSH 的直接启动、新标签、分屏／Workspan、Worktree、恢复和外部终端；项目显式权限参数优先，下次启动生效。自动参数不改写基础命令；存活 daemon 附着不重新执行，手动命令、复杂脚本和 CLI 全局配置不变。

- 项目与分组管理，CLI 工具、启动参数历史、环境变量及 Shell 配置。
- 可从 Finder／文件资源管理器直接拖入一个或多个文件夹创建项目，自动使用文件夹名称、路径和默认 Shell；拖到分组或组内项目时加入对应分组。支持折叠侧栏、拖放目标提示、自动展开与选中、重复目录定位、无效文件过滤及批量部分失败提示；兼容 Windows／WSL 路径与高 DPI 坐标，和终端文件拖放按落点分流。
- 本地、WSL 与 SSH 终端；多标签、拖拽分屏、Workspan、全屏和快捷键。
- PTY daemon、终端输出回放与工作区恢复；按退出策略保留后台任务或终止任务。
- 0.1.0 “终止任务，退出应用”保留标签和对话身份，下次启动按“询问／自动”设置恢复；macOS Cmd＋Q／原生菜单退出与窗口、托盘共享保存流程。拒绝恢复、关闭标签及明确丢弃后台任务仍删除对应恢复数据；旧版已清除的身份需要从历史重新绑定。
- 0.1.0 项目／分屏／Workspan 切换时保留终端画面，按可见区域尺寸完成布局与完整重绘；同帧请求合并，隐藏时撤销过期布局，零尺寸后继续恢复，避免空白、闪烁和文字错位，兼容 WebGL、默认渲染及低内存模式。
- 0.1.0 后台终端默认隐藏 30 秒后释放 GPU 渲染器，低内存模式为 10 秒，最小化／托盘隐藏也参与回收；显示后重建并重绘，PTY 和缓冲区持续保留。回答预览、文件浏览和设置按需加载，简体／英文不初始化繁体转换树；繁体及预览回答选择、本地／WSL／SSH 与 Hook 行为保持可用。
- 0.1.0 项目／分组／Worktree 筛选暂时为空时保持终端挂载；存活会话重挂按原网格恢复光标和备用屏，不追加历史分隔换行。重新启动后重建普通 Shell 时，将旧普通屏与已退出的备用屏归档至滚动历史，新 PTY 从空白首行开始，修复恢复后切换项目导致提示符在底部、输入在首行的问题；隐藏项目首次显示与尺寸变化遵守相同坐标边界。内存快照逐会话隔离、恢复后消费、关闭时释放，异步解析期间冻结尺寸；本地／WSL／SSH 共用恢复显示流程，Worktree、Hook 状态与安装逻辑保留。
- 0.1.0 Windows 窗口最大化／还原及返回前台时，统一适配终端网格并完整重绘；异步回放保持历史解析尺寸，提交后显式同步 PTY 最终尺寸，避免异常窄列、提示符错位和空白。预览开关与快照恢复遵守同一尺寸边界，隐藏标签及分屏可见后再同步；保留滚动位置、Workspan／Worktree 和本地／WSL／SSH 与 Hook 状态。
- 0.1.0 重建终端可按当前实际 Agent 与准确会话 ID 重新打开 Claude／Codex／Grok／Pi 原对话并继续聊天，包括手动启动和切换工具；身份由 Hook 等精确绑定提供，不按目录选择“最近一次”。退出前冻结最终恢复数据，关闭事件不清掉原对话；退出失败恢复保存，丢弃操作继续清除。保留分屏／Workspan、Worktree、WSL 启动包装和 SSH 主机／原目录；存活 daemon 直接附着。缺少 ID 或工具不支持时保留画面并提示从历史选择，既有缺失身份无法自动补回。
- 0.1.0 静态快照、daemon 附着和断线回放统一隔离历史终端应答，避免能力／光标查询在恢复时被当作 Shell 输入。异步解析退出后再解除隔离并同步尺寸，防止当前写入递归回放；各终端独立处理，覆盖后台／隐藏、分屏／Workspan、Worktree 与本地／WSL／SSH，保留正常输入、实时查询、颜色、备用屏和历史文件。
- 重建普通 Shell 时，静态历史画面去除旧鼠标跟踪、焦点上报、应用键盘及粘贴协议，防止移动鼠标继续写入坐标乱码；保留原文、颜色和显示状态。存活 daemon 继续恢复运行中 TUI 的状态，新 Shell／Agent 可从实时输出重新开启自己的协议；ConPTY 自定义应答同样服从回放隔离。
- 存活 Agent 快照完整保存鼠标编码（SGR／像素／传统），避免恢复后移动鼠标注入 `[MC…` 乱码；覆盖定时 checkpoint、卸载保存、分片回放及终端重置。旧快照编码缺失时仅暂停未确认的鼠标上报，收到明确编码协商后恢复；不阻断键盘、粘贴或新启动 TUI 的传统鼠标协议，分屏及不同终端独立隔离。
- 本机终端每秒自动识别手动启动的前台 Agent（原生 CLI 与已知解释器启动脚本），退出、挂起或切换时更新标签、工作区卡片和当前会话来源，清除旧会话绑定；后台／隐藏窗口、分屏、Workspan、同目录多终端和 Worktree 分别绑定，重连携带最新状态。进程存在不等同于正在工作，精确状态仍来自 Hook。SSH／WSL 目前保留客端 Hook 绑定，本机进程扫描不确认远端 Agent 的存活或退出。
- 0.1.0 Pi 进程识别兼容 `@earendil-works/pi-coding-agent`、旧版 `@mariozechner/pi-coding-agent` 与原生启动入口；当前工作区、Hook 身份校验和内存展示共用识别结果，Pi 的工具子进程计入所属 Agent，各终端独立统计，避免新包名导致未识别或误归入“其他子进程”。
- 终端选择、复制粘贴、文件路径跳转、Markdown 预览、主题和背景图。
- 0.1.0 移植 Unicode 15 字素簇占格与输入法润色重复输入修复；支持组合 emoji、CJK、变体符号、备用屏与回放，保留 Unicode 11 构建回退，升级后新开终端应用规则。
- 回答预览仅在打开且当前窗格／窗口活跃时读取，关闭释放全文，切回可见时刷新；独立隔离同项目分屏／SSH consumer 与迟到请求。快照保存串行合并，退出等待最终画面，关闭／重挂取消旧写屏障，保存失败重试，保留原有历史与终端回滚数据。

## 历史会话

- 0.1.0 取消 AI 进展独立侧栏，事件日志并入会话详情／当前会话信息，支持原始事件展开、搜索、类型筛选和旧会话记录浏览。Git 内集中查看此工作目录的代码快照、差异、确认回退和新分支；保留工作区补丁与 HEAD 校验、全部历史数据库和快照文件。隐藏视图停止读取但 Hook 持续记录，各视图独立选择；SSH 保留事件诊断，远端不调用本地快照操作。从旧会话回退或分叉后始终保存新的工作目录检查点，避免被旧会话内的重复快照去重影响后续操作。

- 0.1.0 会话历史的侧栏、快捷键、命令面板和终端入口默认按当前项目筛选，兼容无终端的项目选择、分屏／Workspan、子代理、文件编辑页、本地／WSL／SSH 与 Worktree。用户仍可手动切换“全部项目”，已打开面板中的筛选不因重复使用全局入口而重置；无当前项目时展示全部历史。

- 0.1.0 历史来源设置与恢复项目列表统一使用完整 Agent 图标映射，覆盖全部 11 类历史来源。

- 0.1.0 历史列表在 Agent 分区下以主会话 44px／子会话 40px 的默认最小行高、20px 逐级缩进和连续祖先连接线表达层级；展开家庭共享淡底色，父会话显示带完整提示的紧凑子代理数量，子代理保留身份、时间与消息数，选中只标记当前记录。组尾留白为 4px，虚拟滚动同步估算并测量实际行高，兼容窄栏及大字号；保留搜索、收藏、批量选择、多级折叠和缺失父链提示。

- 0.1.0 Codex 子代理按转录首条元数据归入主会话，普通 fork 保持独立；兼容 Claude 子转录树，支持多层折叠、代理名称、独立查看及主会话／子代理分别计数。分页、搜索和收藏保留父链，父会话缺失时显示归属提示；本地配置目录、WSL 发行版、SSH 来源实例和 Worktree 工作目录正确区分。旧索引无需改写历史文件即可补齐关系，沿用既有迁移与各来源删除规则。

- 0.1.0 Cursor 历史项目匹配在 macOS／Linux／Windows 使用一致的项目标识比较，兼容 Windows 盘符、WSL UNC 与 Linux 目录；其他本地历史路径保留原有大小写语义。

- 0.1.0 历史列表移除顶部 Agent 来源筛选框，保留简洁标题及刷新／关闭操作；从项目、Worktree 和终端打开时默认展示全部 Agent 的可折叠分组，保留项目范围、搜索、收藏及批量操作。

- 0.1.0 历史来源配置、索引、列表、项目和来源过滤、全文搜索及消息浏览。会话默认按 Agent 分组，显示图标、名称与会话数量，各组可独立折叠；组内按更新时间排列，会话行保留时间与消息数，支持子 Agent 会话树、收藏和批量操作，不改写历史文件。
- 0.1.0 历史会话设置采用紧凑来源列表与按需展开的路径编辑，提供独立启用开关、目录浏览、自动检测、保存及清除；折叠、页签切换和其他来源开关不丢失草稿。备份与恢复独立页签展示平面存储指标、备份选择和恢复条件，继续保留恢复确认与冲突阻止。
- Codex 历史会话优先使用 Desktop 保存的名称，兼容标题索引与旧版字段；数据库／WAL 或标题索引变化时，即使会话日志未变化也能同步重命名。缺少名称才回退到实际请求，跳过内部上下文、项目说明和交互回执，原始历史与自定义别名保留。
- Unified Diff 与 Codex Patch 查看、消息定位、原始文件打开及支持来源的会话恢复。
- 按来源能力提供会话编辑、删除、转换与备份，继续兼容既有历史索引。
- 0.1.0 移除跨会话统计、分析看板、请求记录、热力图、费用聚合、定价下载、ccusage 和后台请求同步；对应入口、设置、接口、类型、缓存及依赖一并移除。
- 保留旧数据库迁移及兼容列，不清空用户的 CLI 历史日志。

## 当前会话信息与系统资源

- 0.1.0 应用内存与系统、CPU、系统内存、网络、磁盘、GPU、进程排行共用 336×280 紧凑详情浮层；标题／读数／操作和范围／时间固定，内容超出时仅在正文滚动，窄窗口按可用空间收缩。容量数字、72px 趋势、键值行和分区列表统一密度，保留应用内存与系统内存的不同图标。

- 0.1.0 底栏所有资源入口共用 22px 按钮、固定图标槽和数值槽，应用内存与系统资源的图标、文字及读数统一垂直居中；支持键盘聚焦、打开态和窄窗口横向滚动。

- 0.1.0 系统采样在窗口隐藏／最小化时暂停，手动刷新与定时请求共用并发限制；关闭、重开及配置切换后丢弃旧采样结果。

- 0.1.0 底部应用内存与系统资源使用独立详情入口：应用内存保留框架分类与各终端标签总量，系统资源提供七类单项详情、趋势和进程排行。资源设置统一放在底部“自定义监控卡片”，保留显示开关、上移／下移、恢复顺序和全部显示；移除设置页重复分区，沿用已保存的显示与排序配置，保留会话实时统计卡片设置。可见资源共享采样和有限趋势缓存，进程明细仅在打开排行时读取，本地／WSL／SSH 均明确按本机范围展示。

- 0.1.0 内存统计、Agent 进程识别和运行诊断逐级校验父子进程启动时间，排除 Windows 父 PID 被复用后错误连接的系统进程与其他应用；保留同秒启动的正常父子进程、独立终端归属及 WSL／SSH 本机统计边界。

- 0.1.0 内存面板按终端标签逐行展示总内存，包含 Shell、Agent 和全部子进程，不再拆分标签内的分类；标出当前标签，保留框架统计、不可用状态及 WSL／SSH 的本机范围提示。

- 当前终端会话的 Token/上下文、模型、工具/MCP 调用及运行状态；支持面板卡片和顺序设置。
- 右侧实时统计、Git 与文件工具采用统一的下划线标签、平面标题栏和轻量分区；默认跟随应用深浅配色，保留独立皮肤、合并／独立显示、面板宽度调整、图表和状态色。
- 保留单个会话上下文和 Token 趋势展示，不再汇总“今日项目用量”。
- 系统 CPU、内存、进程及其他可用资源信息仍属于系统资源面板。
- macOS 按系统责任进程识别 launchd 启动的本应用 WebKit 渲染、GPU 与网络服务，计入渲染及合计内存；与其他应用的同名进程隔离，保持现有终端／Agent 归属及隐藏时暂停采样。

- 0.1.0 统一“任务”侧栏同时展示当前主会话的子代理与后台任务，两类任务共用紧凑行、状态和操作对齐；主会话范围位于分组标题，分组可独立折叠，计数与空状态共用一个滚动区域及顶部刷新。后台任务按待处理／失败、运行、完成优先级及更新时间排序，真实进度有界显示、未知进度不虚构百分比。完整任务名、路径、ID 和 24 小时时间保留提示；继续支持已结束子代理查看、后台终端恢复／丢弃确认、后台操作重试、错误详情复制及 SSH 安装任务。恢复期间阻止重复操作，沿用本地／WSL／SSH、分屏／Workspan 与 Hook 身份边界。

## Hook 通知

- 0.1.0 普通子代理工具活动不视为启动通知；Claude 未知 `agentId` 只有在通过只读探测读到真实子转录内容后才补建标签，保留 WSL 缺少启动回调时的兼容路径。不存在、空白或无可读消息的转录不创建空标签或 tail，探测期间关闭父会话、切换 Agent、手动关闭结果或改变 Workspan 后按最新状态处理，SSH 继续隔离远端链路。
- 0.1.0 子代理结束 Hook 仅刷新已有且身份匹配的结果标签；Claude 内置功能的结束事件、陌生 ID、手动关闭后的迟到回调不会自动创建空白分屏，缺少身份时也不按父终端推断另一个子代理。保留真实启动、本地／WSL 转录订阅、任务列表手动打开已完成结果与 SSH 远端链路。
- 0.1.0 子代理结束事件身份校验覆盖 Claude、Codex、Grok 及 Codex 子回合 Stop／StopFailure；Pi 等主会话普通结束回调保留原处理，SSH Claude／Codex 生命周期事件继续隔离在远端链路，不创建本地转录分屏。
- 0.1.0 Hook 身份归一化兼容 Grok 的 `subagentId/subagentType` 与顶层 camelCase 字段；同一子代理的启动／结束保持一致 ID，不按父终端猜测或合并并发子代理。

- 0.1.0 顶部“任务”侧栏中的子代理分组主动列出当前主会话已有的 Codex／Claude 子代理转录，恢复后无需新 Hook；手动查看不受自动分屏开关限制。本地／WSL 使用当前来源配置，SSH 经远端历史链路读取，保留父子身份校验与异步切换隔离。
