# CLI-Manager 精简版功能清单

> 版本：0.1.0（开发中，未发布）
> 更新：2026-10-20。本文记录当前精简分支的功能边界；历史版本的变更请查看 CHANGELOG.md。

## 项目和终端工作区

- 项目与分组管理，CLI 工具、启动参数历史、环境变量及 Shell 配置。
- 可从 Finder／文件资源管理器直接拖入一个或多个文件夹创建项目，自动使用文件夹名称、路径和默认 Shell；拖到分组或组内项目时加入对应分组。支持折叠侧栏、拖放目标提示、自动展开与选中、重复目录定位、无效文件过滤及批量部分失败提示；兼容 Windows／WSL 路径与高 DPI 坐标，和终端文件拖放按落点分流。
- 本地、WSL 与 SSH 终端；多标签、拖拽分屏、Workspan、全屏和快捷键。
- PTY daemon、终端输出回放与工作区恢复；按退出策略保留后台任务或终止任务。
- 0.1.0 重建终端可按当前实际 Agent 与准确会话 ID 重新打开 Claude／Codex／Grok／Pi 原对话并继续聊天，包括手动启动和切换工具；身份由 Hook 等精确绑定提供，不按目录选择“最近一次”。退出前冻结最终恢复数据，关闭事件不清掉原对话；退出失败恢复保存，丢弃操作继续清除。保留分屏／Workspan、Worktree、WSL 启动包装和 SSH 主机／原目录；存活 daemon 直接附着。缺少 ID 或工具不支持时保留画面并提示从历史选择，既有缺失身份无法自动补回。
- 0.1.0 静态快照、daemon 附着和断线回放统一隔离历史终端应答，避免能力／光标查询在恢复时被当作 Shell 输入。异步解析退出后再解除隔离并同步尺寸，防止当前写入递归回放；各终端独立处理，覆盖后台／隐藏、分屏／Workspan、Worktree 与本地／WSL／SSH，保留正常输入、实时查询、颜色、备用屏和历史文件。
- 重建普通 Shell 时，静态历史画面去除旧鼠标跟踪、焦点上报、应用键盘及粘贴协议，防止移动鼠标继续写入坐标乱码；保留原文、颜色和显示状态。存活 daemon 继续恢复运行中 TUI 的状态，新 Shell／Agent 可从实时输出重新开启自己的协议；ConPTY 自定义应答同样服从回放隔离。
- 本机终端每秒自动识别手动启动的前台 Agent（原生 CLI 与已知解释器启动脚本），退出、挂起或切换时更新标签、工作区卡片和当前会话来源，清除旧会话绑定；后台／隐藏窗口、分屏、Workspan、同目录多终端和 Worktree 分别绑定，重连携带最新状态。进程存在不等同于正在工作，精确状态仍来自 Hook。SSH／WSL 目前保留客端 Hook 绑定，本机进程扫描不确认远端 Agent 的存活或退出。
- 终端选择、复制粘贴、文件路径跳转、Markdown 预览、主题和背景图。
- 0.1.0 移植 Unicode 15 字素簇占格与输入法润色重复输入修复；支持组合 emoji、CJK、变体符号、备用屏与回放，保留 Unicode 11 构建回退，升级后新开终端应用规则。
- 回答预览仅在打开且当前窗格／窗口活跃时读取，关闭释放全文，切回可见时刷新；独立隔离同项目分屏／SSH consumer 与迟到请求。快照保存串行合并，退出等待最终画面，关闭／重挂取消旧写屏障，保存失败重试，保留原有历史与终端回滚数据。

## 历史会话

- 历史来源配置、索引、列表、项目和来源过滤、时间分组、全文搜索及消息浏览。
- 0.1.0 历史会话设置采用紧凑来源列表与按需展开的路径编辑，提供独立启用开关、目录浏览、自动检测、保存及清除；折叠、页签切换和其他来源开关不丢失草稿。备份与恢复独立页签展示平面存储指标、备份选择和恢复条件，继续保留恢复确认与冲突阻止。
- Codex 历史会话优先使用 Desktop 保存的名称，兼容标题索引与旧版字段；数据库／WAL 或标题索引变化时，即使会话日志未变化也能同步重命名。缺少名称才回退到实际请求，跳过内部上下文、项目说明和交互回执，原始历史与自定义别名保留。
- Unified Diff 与 Codex Patch 查看、消息定位、原始文件打开及支持来源的会话恢复。
- 按来源能力提供会话编辑、删除、转换与备份，继续兼容既有历史索引。
- 0.1.0 移除跨会话统计、分析看板、请求记录、热力图、费用聚合、定价下载、ccusage 和后台请求同步；对应入口、设置、接口、类型、缓存及依赖一并移除。
- 保留旧数据库迁移及兼容列，不清空用户的 CLI 历史日志。

## 当前会话信息与系统资源

- 当前终端会话的 Token/上下文、模型、工具/MCP 调用及运行状态；支持面板卡片和顺序设置。
- 右侧实时统计、Git 与文件工具采用统一的下划线标签、平面标题栏和轻量分区；默认跟随应用深浅配色，保留独立皮肤、合并／独立显示、面板宽度调整、图表和状态色。
- 保留单个会话上下文和 Token 趋势展示，不再汇总“今日项目用量”。
- 系统 CPU、内存、进程及其他可用资源信息仍属于系统资源面板。

## Hook 通知

- 按 CLI 能力安装与卸载 Hook，绑定会话并显示完成、错误或审批通知，支持跳回终端。
- 0.1.0 任务提醒统一使用系统通知，移除应用内任务弹窗；前台可见终端始终不弹窗，默认应用聚焦时全部静默，可允许后台标签提醒。发送前后核对窗口焦点、隐藏／托盘／最小化、分屏、Workspan、项目过滤及实际窗格可见性，权限确认期间切回前台取消提醒；本地／WSL／SSH／Worktree 统一处理，Hook 状态更新、标签标记和通知跳转保留。
- 0.1.0 删除已经失效的 CC Switch 保护 UI、类型及提示，使设置页与后端一致。
- 旧 Claude 配置执行 __statusline 时静默退出，避免反复打开主窗口；不再提供 Statusline 管理。

## SSH、文件与 Git

- SSH 主机及分组、认证、配置导入、连接测试、远端项目和 SSH Agent 管理。
- 本地／WSL 文件浏览与编辑，Git 状态、Diff、暂存、提交和远程操作；SSH 工具面板目前提供只读文件、Git 与历史视图，暂不支持远端面板写操作及 Worktree 管理，可继续在远端终端直接执行命令。
- Worktree 创建、终端绑定、完成与清理；0.1.0 移除 Trellis 身份文件复制。
- SSH Agent 保留独立版本、协议能力校验及签名验证，不依赖桌面更新器配置。

## 桌面界面（0.1.0 重设计）

- macOS 原生窗口按钮与覆盖式标题栏，项目标题和终端标签在同一行；支持窗口关闭、最小化、缩放与全屏。
- 主界面参考 Orca 的项目／工作区层级：左侧搜索和全局入口、项目标题及主工作区／Worktree 卡片、中央终端、顶部横向标签与工具栏、右侧文件／Git／实时信息面板和会话历史列表、全局底部状态栏。
- 项目使用文件夹代码图标，标题菜单提供项目设置、收起工作区、新建 Worktree、从项目创建分组和移除；工作区显示真实分支、主要标记、终端运行状态、本地／WSL／SSH 环境及已打开终端。保留原有终端、分屏、历史、文件和 Worktree 操作，支持复制工作区路径和名称。
- 搜索支持项目名、目录、CLI 与 Worktree，提供清除、Escape 及方向键导航；搜索、全局入口和底栏固定，项目列表独立滚动，支持紧凑／折叠侧栏、分组浮层及拖入文件夹。新安装默认按项目筛选终端，保留已有设置。
- 历史列表可以停靠右侧并与终端同时显示；打开会话后展开详情，支持返回终端。分屏和 Workspan 终端保持挂载，保留历史搜索、Diff、恢复和编辑功能。
- 左侧底部提供设置、Hook 状态及远程主机入口；全局状态栏提供当前项目／分支、环境、终端数量和本机内存入口。内存明细按应用框架、Shell、Agent、后台和未归属进程分组，保留 5 秒更新、手动刷新、失败提示和隐藏／最小化暂停；SSH／WSL 只统计本机连接进程。
- 暖白/炭灰的低饱和深浅主题，单色主按钮、轻量悬停和选中态；现有配色偏好继续有效，状态色用于运行、错误和审批等信息。
- 终端默认跟随应用，提供炭灰与暖纸配色，正文／光标、选择区与 ANSI 颜色适配深浅背景；旧森林绿默认组合在升级时一次性迁移，自选主题、字体、文字覆盖色与背景图保留。设置支持中英文及繁体转换。
- 工作区首页集中提供终端与历史入口；项目树去除图标底纹和分组卡片，标签栏、工具栏及空状态去除渐变、发光和浮起效果。
- 设置采用居中窗口、紧凑分类导航、统一表单间距及配色下拉框；窄窗口使用图标导航，保留 aria 标签、焦点与滚动能力。
- CPU 查看入口使用线性图标，保留用量提示和资源面板跳转；关于页使用简洁文字与仓库链接。
- 历史详情使用紧凑单色工具栏，低频操作收进更多弹层，收藏保留直接入口；别名/标签按需编辑，搜索使用单行匹配导航及 Enter / Shift+Enter；视图使用下划线选中态，列表与消息使用中性底色、线性角色图标。弹层支持 Escape 关闭及焦点返回，所有原操作继续可用。
- 新文案提供中文和英文；18 个配色的主文字、次级文字和辅助文字对背景对比度均达到 4.5:1。

## 模板、设置和数据

- 全局/项目/会话命令模板、命令面板、快捷键和终端主题。
- 0.1.0 支持从本应用终端的最近命令创建模板：自动记录本地 Zsh／Bash／Git Bash／PowerShell 确认执行的单行命令，按项目搜索、去重显示，选择后填入模板并由用户保存；提供记录开关和历史清除，过滤常见凭据及空格开头的命令，不采集 Agent 对话与子进程交互。记录按 PTY 绑定，兼容分屏／Workspan／Worktree，回放不重复入库；不读取系统历史，不修改用户 Shell 配置，开启后新建终端生效。WSL／SSH、Fish／Sh／CMD 与自定义 Shell 路径暂不采集。
- 简体中文、繁体中文及英文；时间使用 24 小时制。
- 安装版/便携版数据目录选择与迁移、日志和开发者诊断。
- 0.1.0 关于页显示精简版版本与项目链接，移除完整版上游自动更新链路；完成精简后再发布。

## 已移除的功能和开发工具

- 桌宠、供应商管理和配置注入、命令建议、Statusline 管理、cc-connect、WebDAV 同步。
- 历史统计、请求记录、ccusage、今日项目用量及完整版自动更新。
- Trellis 任务系统、脚本、规范、任务归档、研究子仓库和工作记录；不再创建 Trellis task。
